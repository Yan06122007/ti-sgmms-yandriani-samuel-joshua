# Sistema de Gestión y Monitoreo de Movilidad y Seguridad — SGMMS

Tarea Integradora — Ingeniería de Software II / Algoritmos y Programación II / Computación y Estructuras Discretas I
Facultad Barberi de Ingeniería, Diseño y Ciencias Aplicadas — Universidad Icesi

## Descripción del proyecto

Prototipo de aplicación de escritorio en Java, con interfaz gráfica, que simula el
comportamiento de la ciudad de Palmira y apoya a un operador de un centro de
monitoreo urbano en la identificación, priorización y atención de incidentes
(accidentes, robos e incendios) mediante la asignación de vehículos de atención
disponibles y compatibles.
